# Sihirli Menü ✨

Bu proje, HTML/CSS ile yapılmış animasyonlu menü örneğini React Native'e uyarladığımız bir Expo uygulamasıdır.

## Özellikler

- 🎨 Animasyonlu menü bar
- 📱 iOS, Android ve Web desteği
- 🎯 Yukarı doğru yükselen ikon animasyonları
- ✨ Aktif menü öğesi için parlayan efekt
- 🏷️ Dinamik label gösterimi

## Kurulum ve Çalıştırma

1. Bağımlılıkları yükleyin

   ```bash
   npm install
   ```

2. Uygulamayı başlatın

   ```bash
   npx expo start
   ```

Uygulamayı şu seçeneklerle açabilirsiniz:

- [development build](https://docs.expo.dev/develop/development-builds/introduction/)
- [Android emulator](https://docs.expo.dev/workflow/android-studio-emulator/)
- [iOS simulator](https://docs.expo.dev/workflow/ios-simulator/)
- [Expo Go](https://expo.dev/go)

## Proje Yapısı

- `components/magic-menu.tsx` - Animasyonlu menü bileşeni
- `app/(tabs)/index.tsx` - Anasayfa
- `app/(tabs)/profile.tsx` - Profil sayfası
- `app/(tabs)/messages.tsx` - Mesajlar sayfası
- `app/(tabs)/photos.tsx` - Fotoğraflar sayfası
- `app/(tabs)/settings.tsx` - Ayarlar sayfası
- `app/(tabs)/_layout.tsx` - Tab layout konfigürasyonu
